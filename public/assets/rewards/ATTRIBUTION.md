# Pokémon artwork attribution

The four character PNGs in this folder were downloaded from the
[PokéAPI sprites repository](https://github.com/PokeAPI/sprites) at commit
[`2ecb4ee`](https://github.com/PokeAPI/sprites/commit/2ecb4eeacd5a1718621fc30f12772e3f60d830b9):

- `charizard-official.png` — `sprites/pokemon/other/official-artwork/6.png`
- `snorlax-official.png` — `sprites/pokemon/other/official-artwork/143.png`
- `gengar-official.png` — `sprites/pokemon/other/official-artwork/94.png`
- `blastoise-official.png` — `sprites/pokemon/other/official-artwork/9.png`

`pikachu-ending.webp` and `eevee-ending.webp` are 4:3 ending scenes generated for
this project with an image generation tool (bright 2D children's animation tone,
no text, logos, battles, or scary elements). They are stored at 1000px WebP; the
1448px PNG originals stay out of the repository because of their size.
