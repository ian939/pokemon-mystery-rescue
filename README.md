# 포켓몬 미스터리 구조대

6~8세 어린이가 iPad 가로 화면에서 관찰하고 생각하며 진행하는 비상업 팬 메이드 방탈출 PWA입니다.
리자몽·잠만보·팬텀·거북왕의 네 사건, 총 24개 퍼즐과 네 장의 최종 도감을 담았습니다.

**테스트 링크:** https://ian939.github.io/pokemon-mystery-rescue/

## 네 개의 사건

| 사건 | 이야기 | 최종 도감 |
|---|---|---|
| 리자몽 · 불꽃 등대 | 폭풍으로 뒤엉킨 여섯 장치를 복구해 귀항길의 봉화를 되살립니다 | 하늘불꽃의 수호자, 리자몽 |
| 잠만보 · 달빛 축제 | 열매 향기와 자장가를 모아 밤새 축제길을 지킨 잠만보를 다정하게 깨웁니다 | 달빛 축제의 주인공, 잠만보 |
| 팬텀 · 유령 극장 | 조명과 그림자 단서를 풀어 겁주는 대신 웃음을 주는 공연을 엽니다 | 웃음 무대의 마술사, 팬텀 |
| 거북왕 · 산호 수문 | 압력과 수로를 맞춰 항구와 산호밭에 맑은 물길을 돌려보냅니다 | 푸른 항구의 대장, 거북왕 |

사건은 위 순서대로 열립니다. 각 사건을 해결하면 해당 포켓몬의 번호·분류·타입·사건 기록이 들어간 도감 카드가 저장됩니다.

## 퍼즐 24개

각 사건에는 한글, 영어, 수학, 규칙, 공간, 지도 영역을 섞은 여섯 퍼즐이 있습니다.

| 포켓몬 | 퍼즐 |
|---|---|
| 리자몽 | 반대말 항해 일지 · 영어 바람 신호 · 봉화 수 모으기 · 렌즈 패턴 · 날개 대칭 · 봉화 암호 |
| 잠만보 | 열매 문장 · 열매 세기 · 음표 수열 · 영어 방향 종 · 담요 그림자 · 축제길 지도 |
| 팬텀 | 초대장 문장 · 전구 패턴 · 영어 소품 · 거울 복도 방향 · 장난 그림자 · 조명 암호 |
| 거북왕 | 수문 반대말 · 압력계 세기 · 물 에너지 합 · 밸브 수열 · 조준판 대칭 · 산호 수로 |

난이도는 시작 화면 또는 보호자 화면 오른쪽 위에서 바꿉니다.

- 1단계: 현재 학습 수준의 기본 문제
- 2단계: 항목과 단계가 늘어난 응용 문제
- 3단계: 철자 쓰기, 복합 규칙, 계산 암호, 뒤집힌 모양, 최단 경로
- 힌트: 퍼즐마다 최대 2개, 점수나 감점 없음

## 화면 설계

기존 UI의 원칙을 유지합니다. 방·지도·도감은 어두운 잉크빛 탐험 공간이고, 퍼즐은 그 위에 종이테이프로 붙인 모눈 수첩처럼 보입니다.

| 색 | 토큰 | 역할 |
|---|---|---|
| 고무도장 빨강 | `--stamp` | 해결 완료 |
| 램프 호박색 | `--lamp` | 지금 누를 차례 |
| 신호 청록 | `--signal` | 선택 또는 빈칸 강조 |

## 로컬 실행

```bash
npm install
npm run dev
```

같은 Wi-Fi의 iPad에서 개발 PC의 네트워크 주소로 접속할 수 있습니다. HTTPS로 배포된 페이지는 Safari 공유 메뉴에서 `홈 화면에 추가`할 수 있습니다.

## 검증

미리 `npm run preview`를 실행한 뒤 테스트합니다.

```bash
npm run check
npm run build
npm run test:touch       # 1024×768 터치 영역·제스처·화면 넘침
npm run test:flow        # 난이도 1의 24개 퍼즐·도감·저장·오프라인
npm run test:difficulty  # 난이도 3의 24개 퍼즐·힌트 2개 상한
```

## GitHub Pages

`main` 브랜치에 푸시하면 [배포 워크플로](.github/workflows/deploy-pages.yml)가 `npm run build:github`을 실행하고 GitHub Pages에 배포합니다. 저장소 하위 경로에서도 manifest, 웹폰트, 도감 이미지, 서비스워커 캐시가 작동하도록 구성되어 있습니다.

## 데이터와 어린이 안전

- 별명·설정·진행 기록은 IndexedDB와 localStorage에만 저장합니다.
- 계정, 이메일, 위치, 사진, 음성을 수집하지 않습니다.
- 아이 화면에서는 핀치·더블탭 확대, 텍스트 선택, 길게 누르기 메뉴, 이미지 드래그, 컨텍스트 메뉴, 복사·붙여넣기를 차단합니다.
- 한 손가락 스크롤과 일반 탭은 유지하며, 터치 대상은 최소 44×44 CSS px입니다.
- 성인 확인을 거친 보호자 화면에서는 일반 텍스트 선택과 입력을 허용합니다.
- 진행 초기화는 확인 창에서 2초간 길게 눌러야 실행됩니다.

## 캐릭터 자산과 권리 안내

도감 캐릭터 PNG는 [PokéAPI sprites 저장소](https://github.com/PokeAPI/sprites)의 공식 아트 경로에서 가져왔습니다. 파일별 원본 경로와 기준 커밋은 [ATTRIBUTION.md](public/assets/rewards/ATTRIBUTION.md)에 기록했습니다.

Pokémon 및 캐릭터 이름은 Nintendo, Creatures Inc., GAME FREAK inc.의 상표입니다. 이 저장소는 해당 권리자와 제휴하거나 승인을 받은 제품이 아니며, 캐릭터 자산의 소유권을 주장하지 않는 비상업 팬 프로토타입입니다.
